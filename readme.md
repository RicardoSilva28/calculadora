# 🧮 Calculadora

Projeto de uma calculadora simples desenvolvida com **HTML, CSS e JavaScript**, criada para praticar conceitos básicos de desenvolvimento web e lógica de programação.

## 📌 Sobre o projeto

A calculadora permite realizar operações matemáticas básicas através de uma interface simples e intuitiva.

O projeto foi desenvolvido como prática de **JavaScript**, utilizando funções, manipulação do DOM e eventos através dos botões.

## 🚀 Funcionalidades

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* 🔢 Números decimais
* 🧹 Limpar o display
* ⬅️ Apagar o último caractere
* 🟰 Calcular o resultado
* ⚠️ Tratamento de erros

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 🧠 Conceitos praticados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

* Funções em JavaScript
* Manipulação do DOM
* `querySelector()`
* Alteração do valor de um `input`
* `slice()`
* Eventos através de `onclick`
* Estrutura `try...catch`
* CSS Grid
* Organização de elementos com Flexbox

## ▶️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no **Visual Studio Code**.
3. Abra o arquivo `index.html` no navegador.
4. Utilize os botões da calculadora para realizar os cálculos.

## 📸 Demonstração

A calculadora possui uma interface simples, com um display para mostrar os valores e botões para realizar as operações matemáticas.
